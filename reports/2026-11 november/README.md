# November 2026 report (LaTeX)

The LaTeX report on the two-state (B/C) model, started from the October one (`../2026-10 october/`). Its
parameter table lists the Oriola et al. 2026 values (DO), the July report's (Sotiris) and the current ones,
with the changes since July in red.

| file | what it is |
|---|---|
| `main.tex`, `refs.bib` | the report (pdflatex + biber, as for the July one) |
| `figures/overview.pdf` | the presentation figure (`code-claude/figures/presentation.pdf`, Nov 2) |
| `figures/fig*.png`, `figures/phase_space*.png` | copies of the final figures in `code-claude/figures/` (Nov 2: experiment-like readout with 10-cell clusters and a 50 % core fraction, unconfined aggregates drawn whole with C translucent, area contours) |
| `figures/ring-3layers.png`, `figures/dissolves-muBB1.8.png` | copies of `code-claude/figures/fig6_ring_3layers.png` and `fig7_dissolves_muBB1.8.png` |
| `figures/pol-histogram-*.png`, `figures/fusions-relevant.jpeg` | experimental figures (yours) |

If the figures are redrawn, copy them into `figures/` again: apart from the two renamed ones above, the file
names are the same as in `code-claude/figures/`.

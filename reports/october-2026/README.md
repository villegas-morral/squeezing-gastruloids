# October 2026 report (LaTeX)

The LaTeX report on the two-state (B/C) model, written in the style of the July one
(`../july-2026/report/main.tex`). Its parameter table lists the July report's values next to the current ones,
with the changed values in red.

| file | what it is |
|---|---|
| `main.tex`, `refs.bib` | the report (pdflatex + biber, as for the July one) |
| `figures/overview.pdf` | the presentation figure (`code-claude/figures/presentation.pdf`) |
| `figures/fig*.png`, `figures/phase_space*.png` | copies of the final figures in `code-claude/figures/` (Oct 8) |
| `figures/ring-3layers.png`, `figures/dissolves-muBB1.8.png` | two screen runs (`claude-answers/img/04-*.png`) |

If the figures are redrawn, copy them into `figures/` again: the file names are the same as in
`code-claude/figures/`.
